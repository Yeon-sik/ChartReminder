# 독립 코드 리뷰 지시

```text
이 변경을 구현자가 아니라 독립적인 시니어 풀스택·금융 데이터 엔지니어 관점에서 리뷰하라.

먼저 @GOAL.md, @CLAUDE.md, 관련 기능 명세, @docs/11_DEFINITION_OF_DONE.md를 읽고 git diff와 테스트를 조사하라.

우선순위:
P0 — 데이터 손상, 비밀 유출, 잘못된 금융 결과, 빌드 불가
P1 — 결정론성 위반, 미래 데이터 누출, 시간대/휴장일 오류, Provider 경계 붕괴
P2 — 유지보수성, 테스트 누락, 오류 처리, 성능
P3 — 가독성·경미한 개선

각 문제에 다음을 포함하라.
- 파일과 위치
- 재현 조건
- 실제 영향
- 왜 문제인지
- 최소 수정 방향
- 확신도

근거 없는 스타일 취향은 지적하지 마라. 문제가 없으면 검토 범위와 잔여 위험을 명시하라.
```
