# M5 — MVP UI

```text
@CLAUDE.md, @docs/00_PRODUCT_SCOPE.md, @docs/06_UI_UX_SPEC.md, @docs/10_MILESTONES.md의 M5를 읽어라.

먼저 기존 엔진과 유스케이스를 조사하고 UI가 사용할 view model 경계를 제안하라. 승인된 M5 범위에서 설정 → 데이터 준비 → 재생 → 결과 흐름을 구현하라.

필수:
- BTC/ETH/SOL 중 1~2개 선택
- 기간과 표시 기준
- 일시투자/정기매수 설정
- 데이터 준비 상태
- 재생, 일시정지, 한 단계, restart, 속도
- 상단 가격/정규화 차트
- 하단 원금/평가액 차트
- 결과 요약과 가정
- 로딩, 오류, 빈 상태
- 키보드 조작과 focus-visible
- 미래 데이터 비노출

기능 흐름이 먼저 동작한 뒤 frontend-design Skill을 사용해 시각 품질을 개선하라. 데이터 판독성을 희생하는 장식, 과도한 글래스모피즘, 획일적인 AI 대시보드 스타일을 피하라.

Playwright MCP가 연결되어 있으면 로컬 개발 서버에서 핵심 흐름을 실제 조작하고, 화면·콘솔·키보드 동작을 검증하라. 브라우저 검증은 Tauri 네이티브 통합 테스트를 대체하지 않는다고 보고하라.

완료 후 스크린샷 경로, 테스트 결과, 남은 UX 문제, PROJECT_STATE를 갱신하라.
```
