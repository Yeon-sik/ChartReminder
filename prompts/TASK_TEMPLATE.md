# 기능 작업 프롬프트 템플릿

```text
@CLAUDE.md, @PROJECT_STATE.md와 아래 관련 명세를 읽어라.
- [관련 문서]

목표:
[한 문장]

범위:
- [포함 1]
- [포함 2]

비범위:
- [하지 않을 것 1]
- [하지 않을 것 2]

Acceptance criteria:
- [관찰 가능한 결과]
- [테스트 가능한 결과]

작업 전 기존 구현과 git 상태를 조사하고 계획을 제시하라. 범위를 벗어나지 말고 구현, 테스트, 문서 갱신, 검증까지 끝내라.

완료 보고:
- 변경 파일
- 설계 선택
- 실행 명령과 실제 결과
- 남은 위험
- PROJECT_STATE 갱신
```
