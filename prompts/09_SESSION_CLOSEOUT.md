# 세션 종료 지시

```text
이번 세션을 종료하기 전에 다음을 수행하라.

1. git diff와 git status를 확인한다.
2. 이번 목표와 무관한 변경이 섞였는지 검사한다.
3. format, lint, typecheck, 관련 test, cargo check를 실행한다.
4. 실패를 숨기지 말고 정확히 기록한다.
5. PROJECT_STATE.md를 실제 상태로 갱신한다.
6. 장기 설계 결정은 Decision Log에 기록한다.
7. 다음 세션이 대화 기록 없이도 시작할 수 있도록 다음 작업을 구체적으로 적는다.
8. 변경 파일, 검증 결과, 미해결 위험을 요약한다.

커밋이나 푸시는 사용자가 명시적으로 요청한 경우에만 수행하라.
```
