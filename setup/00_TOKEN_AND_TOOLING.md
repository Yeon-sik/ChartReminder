# Claude Code 도구와 토큰 사용

## 핵심

플러그인이나 MCP 패키지를 컴퓨터에 다운로드하는 행위 자체가 주된 모델 토큰 비용은 아니다. 토큰은 Claude가 세션에서 다음 정보를 읽고 처리할 때 사용된다.

- CLAUDE.md와 자동 로드 규칙
- Skill 설명
- MCP 도구 이름과 필요 시 로드되는 스키마
- Claude가 읽은 파일
- 도구 호출 결과
- 브라우저 DOM, 콘솔, 접근성 트리, 스크린샷 분석 결과
- 대화와 응답

최근 Claude Code는 유휴 MCP의 전체 도구 스키마를 지연 로딩하여 고정 컨텍스트 부담을 줄인다. 그래도 MCP 수가 많거나 실제 도구 호출 결과가 크면 사용량이 증가한다.

## 확인 명령

Claude Code 내부:

```text
/usage
/context
/mcp
```

버전에 따라 제공 화면과 명령은 달라질 수 있으므로 `/help`로 확인한다.

## 절약 원칙

- 사용하지 않는 MCP는 연결하지 않음
- Playwright는 UI 검증 단계에서만 사용
- 긴 스크린샷·DOM 수집을 반복하지 않음
- 한 세션을 무한히 이어가지 않고 PROJECT_STATE에 요약 후 새 세션
- 긴 규칙을 CLAUDE.md에 모두 넣지 않음
- 반복 독립 작업은 subagent로 분리
- 출력이 큰 명령은 필요한 범위만 요청
