# 투자 시뮬레이션 엔진 명세

## 1. 원칙

시뮬레이션 엔진은 가격 경로와 설정을 입력받아 포트폴리오 스냅샷을 생성하는 결정론적 계산 모듈이다.

투자 조언을 생성하지 않으며 실제 주문과 연결하지 않는다.

## 2. MVP 공통 가정

- 체결 가격: 해당 거래일 종가
- 소수점 매수: 기본 허용
- 거래 수수료: 기본 0%, 사용자가 변경 가능
- 세금: 미포함
- 슬리피지: MVP 미포함
- 배당: 미국·한국 주식 Provider가 제공하는 수정주가 정책을 명시적으로 사용하거나 무시
- 환율 통합: 초기 시장별 통화 계산, 교차 통화 비교는 별도 게이트
- 휴장일 정기매수: 예정일 이후 첫 유효 거래일

모든 결과 화면에 현재 가정을 표시한다.

## 3. 일시투자

시작 시점의 첫 유효 거래일에 사용 가능한 투자금으로 매수한다.

필수 계산:

- 매수 가능 금액
- 수수료
- 매수 수량
- 잔여 현금
- 날짜별 시장가치
- 총자산
- 손익
- 수익률
- 최대 낙폭

## 4. 정기 정액매수

지원 주기:

- 매주
- 매월

예정일에 캔들이 없으면 이후 첫 유효 거래일에 한 번만 실행한다. 같은 기간의 여러 누락 예정일이 한 거래일에 중복 실행되는지 여부는 명시적으로 정의하고 테스트한다. MVP 권장 정책은 각 예정 납입을 보존하되 실행 기록을 분리하는 것이다.

## 5. 기여 원금과 현금

정기매수 금액은 외부에서 새로 유입되는 기여 원금으로 취급한다. `contributedCapital`과 `cash`를 혼동하지 않는다.

## 6. 수익률

단순 수익률의 분모는 누적 기여 원금이다.

정기 입출금이 존재할 때 단순 수익률은 시간가중수익률과 다르다. MVP에서는 결과 명칭을 정확히 표시하고, 향후 TWR/MWR를 추가할 수 있게 지표 인터페이스를 분리한다.

## 7. 최대 낙폭

총자산 시계열의 이전 최고점 대비 하락률로 계산한다.

- 최고점 초기화 규칙 명시
- 기여금 유입이 낙폭 계산을 왜곡할 수 있음을 문서화
- MVP의 MDD가 단순 총자산 기준인지 기여금 조정 기준인지 UI에 명시

권장: 초기 MVP는 자산 가격 또는 단위가치 기준 MDD를 제공하고, 총자산 MDD는 별도 표기한다.

## 8. 거래 기록

```typescript
interface SimulatedTrade {
  id: string;
  date: TradingDate;
  type: 'buy';
  executionPrice: DecimalString;
  grossAmount: Money;
  fee: Money;
  quantity: DecimalString;
  reason: 'initial' | 'scheduled';
}
```

## 9. 필수 테스트

- 일시투자 1개 캔들
- 잔여 현금
- 소수점 매수 허용·비허용
- 수수료 0과 양수
- 매주·매월 스케줄
- 휴장일 이월
- 상장 이전 기간
- 데이터 중간 누락
- carried-forward 평가
- Decimal 반올림 정책
- 0원 원금
- 음수 입력 거부
- 최종 수익률 독립 계산과 일치
- 재실행 결과 완전 동일
