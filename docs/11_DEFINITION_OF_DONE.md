# Definition of Done

기능 또는 마일스톤은 아래 조건을 모두 충족해야 완료다.

## 요구사항

- 관련 명세의 acceptance criteria를 충족한다.
- 범위를 벗어난 기능을 추가하지 않았다.
- 사용자에게 보이는 가정과 실제 계산이 일치한다.

## 코드

- 책임 경계가 명확하다.
- React 컴포넌트에 공급자·DB 로직이 침투하지 않았다.
- 불필요한 중복, 죽은 코드, 디버그 출력이 없다.
- 타입 오류를 억지 단언으로 숨기지 않았다.

## 테스트

- 정상·경계·오류 경로가 있다.
- 금융 계산은 독립 기대값과 검산됐다.
- 전체 테스트가 통과한다.

## 품질

- format, lint, typecheck 통과
- `cargo check` 통과
- 관련 build 통과
- 새로운 경고를 방치하지 않는다.

## 문서

- 구현과 명세가 다르면 문서 또는 구현을 정정했다.
- `PROJECT_STATE.md`를 갱신했다.
- 설계 결정이 장기 영향이 있으면 ADR 또는 Decision Log를 갱신했다.

## 보안·데이터

- 비밀정보가 없다.
- 데이터 출처와 이용조건이 기록됐다.
- 사용자에게 기술 오류 세부정보를 과도하게 노출하지 않는다.
