# UI/UX 명세

## 1. 목표

금융 터미널을 복제하지 않는다. 사용자가 “설정 → 재생 → 비교 → 해석” 흐름을 즉시 이해하게 한다.

시각적 개성은 중요하지만, 장식이 데이터 판독을 방해하면 실패다.

## 2. 기본 레이아웃

```text
┌──────────────────────────────────────────────────────────┐
│ 자산 선택 | 기간 | 표시 기준 | 투자 모드 | 세션 실행      │
├──────────────────────────────────────────────────────────┤
│ 현재 날짜 | 재생 | 일시정지 | 한 단계 | 속도 | 진행바      │
├──────────────────────────────────────────────────────────┤
│ 가격 / 정규화 수익률 차트                                │
├──────────────────────────────────────────────────────────┤
│ 기여 원금 / 평가금액 차트                                │
├──────────────────────────────────────────────────────────┤
│ 원금 | 평가액 | 손익 | 수익률 | MDD | 데이터 상태        │
└──────────────────────────────────────────────────────────┘
```

## 3. 초기 화면

- 목적을 한 문장으로 설명
- 자산 1개 기본 선택
- 합리적인 샘플 기간
- 일시투자 기본 모드
- 데이터 출처와 기준 거래쌍 표시
- “시뮬레이션 준비”와 “재생 시작”을 구분

## 4. 차트

### 상단 차트

- 기본값: 시작점 100
- 선택값: 원시 가격, 누적 수익률
- 자산 2개 색상과 범례 명확화
- 현재 공개된 시점까지만 데이터 표시
- 미래 데이터는 DOM, tooltip, 접근성 텍스트에도 노출하지 않는다.

### 하단 차트

- 누적 기여 원금
- 총 평가금액
- 필요한 경우 현금
- 자산별 비교 모드라면 스케일과 범례를 명확히 한다.

## 5. 재생 제어

- Space: 재생/일시정지
- 오른쪽 화살표: 한 단계 전진
- Home 또는 명시 버튼: 처음으로
- 속도 선택
- 진행바 seek는 MVP에서 허용하되 결과 재계산이 결정론적이어야 한다.

## 6. 오류·경고

다음은 서로 다른 메시지여야 한다.

- 인터넷 연결 실패
- 공급자 Rate limit
- 요청 기간 데이터 없음
- 상장 전 기간
- 일부 구간 누락
- 캐시 손상
- 라이선스 또는 인증 설정 필요

기술 스택 트레이스를 사용자에게 노출하지 않는다.

## 7. 접근성

- 모든 제어에 키보드 접근
- 명확한 focus-visible
- 색만으로 상승·하락이나 자산을 구분하지 않음
- 충분한 명암비
- 재생 애니메이션 감소 옵션
- 차트 핵심 수치를 텍스트 요약으로 제공

## 8. 디자인 Skill 사용 시점

`frontend-design` Skill은 M5에서 기능 흐름이 동작한 뒤 적용한다. 먼저 시각적 방향을 제안하고, 사용자의 승인 없이 제품 핵심 레이아웃을 대규모로 변경하지 않는다.
