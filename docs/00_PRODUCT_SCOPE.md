# 제품 범위와 사용자 흐름

## 주 사용자

과거 자산 가격을 보는 데 그치지 않고, 특정 투자 방식의 결과를 시간 흐름으로 체감하고 싶은 개인 투자자·학습자다.

이 앱은 전문 주문 단말이나 투자 자문 서비스가 아니다.

## 핵심 사용자 흐름

1. 사용자가 하나 또는 두 개의 자산을 선택한다.
2. 시작일과 종료일을 선택한다.
3. 표시 기준을 선택한다.
4. 투자 모드를 선택한다.
5. 원금·정기매수 금액·주기·수수료 등의 가정을 입력한다.
6. 필요한 데이터가 로컬에 없으면 공급자로부터 조회하고 캐시한다.
7. 앱이 세션을 준비하고 첫 날짜에서 멈춘다.
8. 사용자가 재생한다.
9. 날짜가 진행될 때 가격 차트와 투자금 차트가 같은 가상 시계로 갱신된다.
10. 사용자가 최종 결과와 위험 지표를 확인한다.
11. 세션을 저장하거나 결과를 내보낸다.

## 필수 화면 상태

- 최초 진입
- 설정 입력
- 데이터 조회 중
- 데이터 준비 완료
- 재생 중
- 일시정지
- 완료
- 부분 데이터 또는 누락 데이터 경고
- 공급자 제한 오류
- 네트워크 오류
- 로컬 캐시 사용 상태

## 비교의 의미

비교 자산이 서로 다른 가격·통화를 갖기 때문에 기본 비교 모드는 `시작점 100` 또는 `누적 수익률`이어야 한다.

원시 가격 비교는 사용자가 명시적으로 선택할 때만 보여준다.

## 비기능 요구사항

- 결정론성
- 재현 가능성
- 데이터 출처 추적 가능성
- 가정의 투명성
- 오프라인 캐시 재사용
- Provider 교체 가능성
- 사용자 데이터의 로컬 우선 처리
- 접근 가능한 키보드 조작과 명확한 포커스
