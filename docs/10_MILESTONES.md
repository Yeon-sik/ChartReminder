# 마일스톤

각 마일스톤은 독립적인 검증 게이트다. 이전 게이트가 닫히지 않으면 다음 단계로 넘어가지 않는다.

## M0 — 저장소 기반과 기술 검증

### 목표

빈 저장소를 실행 가능한 Tauri 2 + React + TypeScript 프로젝트로 만들고 반복 가능한 품질 검증 기반을 만든다.

### 작업

- 현재 환경과 문서 검토
- Tauri 공식 스캐폴딩
- 프로젝트 구조 결정 기록
- format, lint, typecheck, test, cargo check 스크립트
- 기본 CI 또는 최소 로컬 검증
- 앱 시작 화면
- `PROJECT_STATE.md` 갱신

### 완료 기준

- 개발 모드 실행
- 테스트 실행
- `cargo check` 통과
- production build 또는 최소 Tauri build 사전 검증
- 불필요한 기능 없음

## M1 — 순수 도메인과 Golden Fixture

### 목표

UI 없이 공통 Instrument, Candle, Decimal, 타임라인과 검산 fixture를 완성한다.

### 완료 기준

- 도메인 불변조건 테스트
- 5~10일 고정 데이터 fixture
- 독립 기대값 문서화

## M2 — 암호화폐 Provider와 로컬 캐시

### 목표

BTC, ETH, SOL 일봉을 조회·정규화·검증·SQLite 캐시한다.

### 완료 기준

- 누락 범위 조회
- 동일 기간 재조회 시 캐시 사용
- Provider 계약 테스트
- 출처와 거래쌍 표시

## M3 — 리플레이 엔진

### 목표

가짜 시계로 완전 테스트 가능한 상태 머신을 구현한다.

### 완료 기준

- 모든 상태 전이 테스트
- 속도·seek·restart
- 자산 거래일 합집합 처리

## M4 — 투자 시뮬레이션 엔진

### 목표

일시투자와 정기 정액매수를 정확하게 계산한다.

### 완료 기준

- Golden fixture와 결과 일치
- 수수료, 소수점, 휴장일 이월
- 원금·평가액·손익·수익률·낙폭

## M5 — MVP UI

### 목표

설정부터 재생·결과까지 전체 사용자 흐름을 구현한다.

### 완료 기준

- 두 자산 비교
- 두 차트 동기화
- 키보드 재생 제어
- 오류·로딩·빈 상태
- frontend-design Skill을 사용한 시각 검토

## M6 — Crypto Alpha Desktop Release

### 목표

다른 Windows 사용자가 설치 가능한 암호화폐 전용 알파를 만든다.

### 완료 기준

- `.exe` 또는 `.msi`
- 새 환경 설치 테스트
- 캐시·세션 저장
- CSV/JSON 내보내기
- GitHub Release 초안

## M7 — 미국 주식 Provider

### 목표

미국 주식 일봉과 수정주가 정책을 공통 엔진에 연결한다.

### 게이트

- 데이터 이용조건 문서화
- 통화·거래일·분할·배당 정책
- Provider 계약 테스트

## M8 — 한국 주식 Provider

### 목표

한국 주식 일봉을 안전한 인증과 이용조건 범위에서 연결한다.

### 게이트

- 인증정보 보안 저장
- KST 거래일·휴장일
- 개인용과 공개 배포 가능 범위 구분
- 이용조건 승인

## M9 — 통합 MVP Release

### 목표

암호화폐, 미국·한국 주식의 지원 범위를 명확히 하고 공개 가능한 설치본을 만든다.

### 완료 기준

- 설치·업데이트·삭제 검증
- 데이터 출처와 가정 표시
- 알려진 한계
- 사용자 테스트
- 릴리스 노트

## M10 — 후속 공유 기능

MVP 이후에만 평가한다.

- 결과 PNG
- GIF 또는 영상
- 웹 공유 뷰어
- 클라우드 세션
