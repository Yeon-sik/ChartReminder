# 보안과 데이터 이용조건

## 1. 보안 경계

이 앱은 실제 주문을 수행하지 않지만, 향후 주식 공급자 연결 시 API 키·OAuth 토큰을 다룰 수 있다.

## 2. 비밀정보

- 저장소에 커밋 금지
- `.env`를 데스크톱 앱의 비밀 저장소로 오해하지 않음
- 배포 바이너리에 개발자 공용 비밀키를 내장하지 않음
- 사용자 키는 운영체제 보안 저장소 또는 검증된 Tauri 보안 저장 방식을 사용
- 로그에서 Authorization header와 토큰 제거
- 오류 보고서에 민감정보 포함 금지

## 3. Tauri 권한

- 필요한 capability만 허용
- 파일 시스템 범위 최소화
- 임의 shell 실행 금지
- 외부 URL 열기 제한
- CSP와 허용 도메인 검토
- 플러그인 권한을 기본 허용하지 않음

## 4. 공급망

- 의존성 수를 통제
- 공식 또는 신뢰 가능한 유지관리 프로젝트 우선
- lockfile 커밋
- 릴리스 전 감사 및 알려진 취약점 확인
- 출처 불명의 Claude Skill·MCP를 프로젝트에 추가하지 않음

## 5. 금융 데이터 이용조건

무료 조회 가능과 자유로운 재배포 가능은 다르다.

각 Provider 문서에 다음을 기록한다.

- 데이터 소유자
- API 공급자
- 무료/유료 플랜
- 호출 제한
- 개인 사용 허용
- 상업 사용 허용
- 화면 표시 허용
- 캐시 허용
- 재배포 허용
- 출처 표시 의무
- 실시간/지연/과거 데이터 구분

## 6. 출시 게이트

다음 중 하나라도 불명확하면 해당 Provider를 공개 릴리스에서 비활성화한다.

- 상업적 사용 권한
- 제3자 화면 표시 권한
- 데이터 저장·캐시 권한
- 사용자 API 키 사용 조건

## 7. 면책과 표현

- 교육·시뮬레이션 목적을 명시
- 투자 추천처럼 표현하지 않음
- 과거 성과가 미래 수익을 보장하지 않음을 표시
- 데이터 지연·오류 가능성과 계산 가정을 표시
